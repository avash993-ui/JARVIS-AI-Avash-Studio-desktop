قرارداد و قوانین استفاده از جارویس (Avash Studio)

با نصب و استفاده از جارویس، شما با موارد زیر موافقت می‌کنید:

۱. این نرم‌افزار «همان‌طور که هست» ارائه می‌شود و هیچ تضمینی برای عملکرد بی‌نقص یا بدون خطای آن وجود ندارد.

۲. جارویس یک دستیار مستقل است و به هیچ سرویس هوش مصنوعی خاصی وابسته نیست. شما خودتان کلید API سرویسی که انتخاب می‌کنید را وارد می‌کنید و مسئولیت هزینه‌ها و قوانین استفاده از آن سرویس بر عهده‌ی خودتان است.

۳. تنظیمات، مکالمه‌ها و کلیدهای API شما فقط روی همین کامپیوتر ذخیره می‌شوند و هیچ‌وقت به سروری متعلق به Avash Studio ارسال نمی‌شوند.

۴. قابلیت اجرای دستور روی سیستم («اجرا کن») فقط بعد از تایید صریح شما در هر بار، اجرا می‌شود؛ هیچ دستوری بدون تایید شما اجرا نمی‌شود.

۵. استفاده از این نرم‌افزار برای هرگونه فعالیت غیرقانونی ممنوع است.

۶. این نرم‌افزار در حال توسعه است و ممکن است با مشکلاتی روبه‌رو بشید.
