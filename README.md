## 🇬🇧 English

**JARVIS – Avash Studio**

JARVIS is a desktop AI assistant built to make working with your computer easier. You can talk to it, ask questions, and interact with it using either voice or text.

The new version of JARVIS supports **Persian and English**, with support for more languages being added in future updates. You can activate the assistant by saying **"Hey Jarvis"** or its Persian equivalent, **"هی جارویس."**

JARVIS uses APIs to communicate with AI models and is designed with a flexible structure so new features can be added over time.

**Features:**
- Persian and English support
- More languages coming in future versions
- Wake word support: "Hey Jarvis" / "هی جارویس"
- AI conversations
- Voice commands
- Desktop user interface
- API integration
- Extensible and ready for future features

JARVIS is created and developed by **Avash Studio**.

## 🇷🇺 Русский

**JARVIS – Avash Studio**

JARVIS — это ИИ-ассистент для компьютера, созданный для того, чтобы упростить работу с ним. Вы можете разговаривать с ним, задавать вопросы и взаимодействовать голосом или текстом.

Новая версия JARVIS поддерживает **персидский и английский языки**, а поддержка других языков добавляется в будущих обновлениях. Активировать ассистента можно фразой **«Hey Jarvis»** или её персидским эквивалентом **«هی جارویس»**.

JARVIS использует API для связи с моделями ИИ и спроектирован с гибкой архитектурой, позволяющей со временем добавлять новые функции.

**Возможности:**
- Поддержка персидского и английского языков
- В будущих версиях появятся другие языки
- Активация по слову «Hey Jarvis» / «هی جارویس»
- Диалог с ИИ
- Голосовые команды
- Интерфейс для рабочего стола
- Интеграция с API
- Расширяемая архитектура для будущих функций

JARVIS создаётся и разрабатывается студией **Avash Studio**.
