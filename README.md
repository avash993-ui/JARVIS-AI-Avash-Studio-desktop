## 🇮🇷 فارسی

**JARVIS – Avash Studio**

JARVIS یک دستیار هوشمند دسکتاپه که برای راحت‌تر کردن کار با کامپیوتر ساخته شده. می‌تونی باهاش صحبت کنی، سؤال بپرسی و از طریق متن یا صدا باهاش تعامل داشته باشی.

نسخه جدید JARVIS از **فارسی و انگلیسی** پشتیبانی می‌کنه و پشتیبانی از زبان‌های بیشتر هم در حال اضافه شدنه. برای فعال کردن دستیار هم می‌تونی از **«هی جارویس»** یا **«Hey Jarvis»** استفاده کنی.

JARVIS از API برای ارتباط با مدل‌های هوش مصنوعی استفاده می‌کنه و ساختارش طوری طراحی شده که اضافه کردن قابلیت‌های جدید در آینده راحت باشه.

**قابلیت‌ها:**

* پشتیبانی از فارسی و انگلیسی
* پشتیبانی از چند زبان دیگر در نسخه‌های جدید
* فعال‌سازی با «هی جارویس» و «Hey Jarvis»
* گفت‌وگو با هوش مصنوعی
* فرمان صوتی
* رابط کاربری دسکتاپ
* اتصال به API
* قابلیت توسعه و اضافه شدن امکانات جدید

JARVIS توسط **Avash Studio** ساخته و توسعه داده می‌شه.

## 🇬🇧 English

**JARVIS – Avash Studio**

JARVIS is a desktop AI assistant built to make working with your computer easier. You can talk to it, ask questions, and interact with it using either voice or text.

The new version of JARVIS supports **Persian and English**, with support for more languages being added in future updates. You can also activate the assistant using **“Hey Jarvis”** or **“Hey Jarvis” in Persian (“هی جارویس”)**.

JARVIS uses APIs to communicate with AI models and is designed with a flexible structure so new features can be added over time.

**Features:**

* Persian and English support
* More languages coming in future versions
* Wake Word support: “Hey Jarvis” / “هی جارویس”
* AI conversations
* Voice commands
* Desktop user interface
* API integration
* Extensible and ready for future features

JARVIS is created and developed by **Avash Studio**.
